# Quick Look Preview Extension Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Follow the operator's single-writer and review rules.

**Goal:** After a successful, explicitly reviewed feasibility spike, provide an offline sanitized Markdown Quick Look preview using the existing renderer without an Xcode project or widened sandbox permissions.

**Architecture:** An app-sandbox-only view-based `MDViewerQuickLook.appex` has a thin executable shim over the testable `MDViewerQuickLookCore` library, which shares `MDViewerCore`, and its own verified Web resources. A programmatic preview controller performs a one-shot bounded read/render, completes only after a committed DOM, ignores nonfragment links and releases all request state on reuse/teardown. Sign extension first, containing app second; never sign with `--deep`.

**Tech Stack:** SwiftPM/Swift 5.9, AppKit, QuickLookUI, WebKit, ad-hoc codesign, Python plist/resource verification. Deployment target macOS 13.

**Spec:** [Quick Look preview extension](../specs/2026-10-30-quick-look-extension-design.md).

**Execution order:** Feature **1 → 3 → 8 → 7**; this is last. Scroll and Quick Look share `Sources/MDViewerCore/RenderHost.swift`: re-read the post-scroll/post-image version, preserve retained Follow Changes initialization and the committed asset callback, but do not enable Follow Changes or create refresh/image watchers in Quick Look. Its default remains off. The CLI launcher remains a containing-app resource only.

**Permission boundary:** This document authorizes no build, install or launch. Every future command below belongs to implementation, not plan authoring. **Task 1 is mandatory; Tasks 2–7 are conditional on GO.** Before **any** `pluginkit`, `qlmanage`, app/extension installation, launch or registration, STOP and ask the user for that exact command, bundle path, expected persistent effect and cleanup scope. A prior approval of compilation, packaging or a different command does not count. Before **any entitlement beyond `com.apple.security.app-sandbox`**, STOP and ask the user for a security decision and an approved spec amendment. Do not retry with `network.client`, user-selected access, temporary exceptions, relaxed CSP or default-handler changes. Keep `MDVIEWER_M0_ALLOW_LAUNCH_SERVICES` unset throughout automated checks.

Controller entry point is `preparePreviewOfFile(at url: URL, completionHandler handler: @escaping (Error?) -> Void)`. Cancel the preceding request/host before starting a new one; construct `DocumentLocation(url)` then `await DocumentIO.shared.read(location)`. Instantiate `RenderHost`, install its view with constraints, leave `onLink=nil`, wire shell failure into the current request, call `load()`, then `render(source:root:document:completion:)` (it already queues before shell readiness). Core sketch:

```swift
host.render(source: source, root: location.assetRoot,
            document: location.canonicalURL) { [weak self, weak request] result in
    guard let self, let request, self.request === request else { return }
    switch result {
    case .success: request.finish(nil) // native completion follows committed DOM
    case .failure(let error): self.fail(request, error: error)
    }
}
```

Store request ownership on the controller; avoid a completion/task cycle retaining it forever. `fail` replaces preview content with native status text using controlled `ViewerError` descriptions (unexpected errors use a generic “Preview unavailable”), closes host and finishes with an error; never render source/error HTML or log source text. No `DocumentRefresh`, FSEvents, follow preference, find controls or zoom controls. On teardown cancel the request and call `host.close()`; if Swift isolation requires scheduling close from deinit, capture only the old host into a main-actor Task, never self. The controller must also cancel before reuse so it does not rely on deinit timing. A content-process recovery may re-render the same in-memory source only for the current uncompleted request within its original deadline; no reread/watch loop or deadline extension.
