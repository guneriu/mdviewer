**Goal:** Provide an auditable POSIX-shell `mdv` launcher with guarded optional installation at `~/.local/bin/mdv`.

**Architecture:** Validate the entire input list before issuing exactly one `open` command. Package the standalone script as a signed app resource, verifying its bytes/hash and executable mode separately from vendored renderer assets. Extend the existing installer mode parser without weakening its app-copy, signature, symlink or rollback guards.

**Tech Stack:** `/bin/sh`, existing Bash installer/packager, Python standard-library tests, macOS bundle plist tools and ad-hoc signing.

**Spec:** [mdv command-line launcher](../specs/2026-10-30-mdv-cli-design.md).

**Execution order:** Feature **1 → 3 → 8 → 7**. Execute after scroll/image refresh and before Quick Look. This feature does not touch `Sources/MDViewerCore/RenderHost.swift` or pi-files; the existing AppDelegate multi-URL/canonical-window path remains authoritative.

**Authorization:** This plan does not authorize implementation, real installation or launch. Tests must use a recording fake `open`, UUID fake HOME/repo/bundle fixtures under `.build/`, and timeout-bounded subprocesses. No test may call real `open`, `lsregister`, change defaults, use `mdfind`, or set `MDVIEWER_M0_ALLOW_LAUNCH_SERVICES`. Commit commands below are future checkpoints only. C5 requires a separate explicit user approval; it is not part of automated acceptance.

The spec says the “packaged allowlist gains” a file. In actual `scripts/verify_assets.py:14-26`, the source vendor inventory is **exactly four renderer/notice assets**, and `scripts/verify_assets.py:42-43` derives the bundle allowlist from that inventory. Preserve the four-entry vendor manifest: the launcher is not a vendored npm asset. Extend the packaged set explicitly with `bin/mdv`, compare SHA-256/bytes against `scripts/mdv`, and verify mode 0755; do not make renderer rebuilds own a shell script. `scripts/test-packaging.py` currently requires an already packaged release bundle; standalone `scripts/test-mdv.py` must not require a build. The current installer verifies the release **source** before any mode's action: CLI-only operations must branch before that source requirement. Verify the installed app's signature, bundle ID and executable launcher instead; never run repository-relative `verify_assets.py --bundle` on an older installed app.

- [ ] **Step 4 — Write the script with `#!/bin/sh` and `set -eu`.** Use `app=${MDV_APP:-}` and parse `-a` before the file list; accept `--` to terminate options. `-h`/`--help` and `--version` are standalone forms; missing/empty `-a`, extra operands for help/version and unknown options print usage/exit 64. Store no file list in an unquoted string. Validate and rotate the original positional list (a `for` loop expands its operands once):

```sh
for f do
    case "$f" in
        /*) candidate=$f ;;
        *) candidate=./$f ;;
    esac
    case "$f" in
        *.[mM][dD]|*.[mM][aA][rR][kK][dD][oO][wW][nN]) ;;
        *) printf 'mdv: not a Markdown file: %s\n' "$f" >&2; exit 66 ;;
    esac
    if [ ! -f "$candidate" ]; then
        printf 'mdv: missing or non-regular file: %s\n' "$f" >&2; exit 66
    fi
    parent=$(cd -P "$(dirname "$candidate")" && pwd -P) || {
        printf 'mdv: cannot resolve file: %s\n' "$f" >&2; exit 66;
    }
    absolute=$parent/$(basename "$candidate")
    if [ ! -f "$absolute" ]; then
        printf 'mdv: resolved path is missing or non-regular: %s\n' "$f" >&2; exit 66
    fi
    shift
    set -- "$@" "$absolute"
done
```

Prefixing relative paths with `./` protects `dirname`/`basename` from dash-prefixed operands without depending on GNU `--` behavior; no `eval`, `xargs`, Bash arrays, stdin reads or network. `[ -f ]` follows a final symlink as required but rejects FIFOs/directories. Repeat it on the constructed absolute path before adding that path to argv: command substitutions (including `dirname`/`pwd`) strip trailing newlines, so a valid original input can produce an invalid absolute path. After validation, call `open -a "$app" -- "$@"` when app is nonempty, otherwise `open -b de.local.mdviewer -- "$@"`. Place the invocation in an `if` so `set -e` does not discard its status; on failure capture `$?`, print the default-app hint if applicable, and exit with that status. Never pass `-n`, `-g`, `--args`, `--env`.

For `--version`, inspect `"$app/Contents/Info.plist"` when selected; otherwise `"$HOME/Applications/MDViewer.app/Contents/Info.plist"`. Use `/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString'` with errors suppressed and guarded by `if`; missing key/app prints `unknown` and exits 0. No Launch Services query or `mdfind` is needed. `chmod 755 scripts/mdv` during implementation.
